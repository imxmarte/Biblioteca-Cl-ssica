# Biblioteca-Cl-ssica
Trabalho de software aula Algoritmo e Pensamento computacional 

Projeto de software simulando o sistema de uma Biblioteca clássica, utilizando a linguagem C.
Possui acervo de livros, acervo de clientes, cadastro de novos livros e clientes, busca e organização de estoque/dados, adições/informações de empréstimos, remoção e alteração de informações de empréstimo, cliente e livros
